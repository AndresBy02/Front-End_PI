# UCEVA logo attribution

- File: `uceva-logo.png` (vertical institutional logo)
- Source: [Wikimedia Commons file page](https://commons.wikimedia.org/wiki/File:Uceva_Vertical_(png).png)
- Author/attribution: UCEVA (as listed on the Commons file page)
- License: [Creative Commons Attribution-ShareAlike 4.0 International](https://creativecommons.org/licenses/by-sa/4.0/)

The logo is included locally so screens do not rely on the external image host.

`uceva-isotipo.png` is a square crop of the symbol from `uceva-logo.png`, prepared for circular display. The original vertical logo is retained as the source asset.

`uceva-imagotipo.png` es el `IMAGOTIPO-UCEVA.png` recortado (sin los márgenes blancos) y reducido a 1000 px de ancho. Es el logo que usan el menú lateral, el acceso y la página de inicio. El original se conserva como archivo fuente.

## Logos del pie de página

- `ciencias-verdes-igsclac.png`: variante con el contenido más ajustado, proporcionada para el proyecto por el equipo.
- `banner-ingenieria-sistemas.webp`: banner fuente publicado en el sitio oficial de UCEVA: [Ingeniería de Sistemas](https://www.uceva.edu.co/facultad-de-ingenieria/ingenieria-de-sistemas/).
- El pie muestra el banner completo para conservar el logo de Ingeniería de Sistemas y el sello de acreditación juntos.

## Vista previa sin backend

Para revisar el diseño del pie sin iniciar sesión ni conectar la API, ejecuta desde la carpeta `src/frontend_flutter`:

```bash
flutter run -d chrome -t lib/footer_preview.dart
```
